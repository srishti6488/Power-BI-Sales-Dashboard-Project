# 📊 Power BI Sales Dashboard Project

Welcome to the **Power BI Sales Dashboard** project!  
This repository contains a complete business intelligence report built using **Power BI**, along with raw data files (`.csv`) and the `.pbix` project file.

---

## 📁 Project Structure

- `Details.csv` → Contains order-level sales data including Amount, Profit, Quantity, Category, Sub-Category, and Payment Mode
- `Orders.csv` → Includes customer and order metadata such as Order Date, Customer Name, State, and City
- `First Report.pbix` → The interactive Power BI dashboard file

---

## 📌 Key Features of the Dashboard

- **Sales and Profit Analysis** by Category and Sub-Category  
- **Geographical Insights** by City and State  
- **Payment Mode Preferences**  
- **Top Performing Products and Locations**  
- **Interactive Visuals** and Slicers for better data exploration

---

## 🔧 Tools Used

- Power BI Desktop
- Microsoft Excel / CSV
- Data Cleaning and Transformation (Power Query)

---

## 💡 Insights Gained

- 📈 *Electronics* emerged as the highest revenue-generating category  
- 🏙️ Cities like *Mathura*, *Delhi*, and *Mumbai* showed strong performance  
- 💳 *Cash on Delivery (COD)* and *EMI* were popular payment choices
